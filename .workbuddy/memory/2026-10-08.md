## 新增小米 MiMo 模型提供商（commit 9ed2b78）

- 新增 `src/provider/mimo.ts`（`MiMoProvider`）：name `mimo`、sdkType `OpenAI`、
  baseUrl `https://api.xiaomimimo.com/v1`，模型列表走 `baseUrl + /models`（与 Base URL 同源）。
- **选 OpenAI 兼容端点而不是 Anthropic 兼容端点**：MiMo 官方接入文档写明，Anthropic
  协议下含工具调用的多轮会话缺 `reasoning_content` 会被判 400，而 Agent 循环重度依赖工具调用。
- Token Plan 订阅用户用专属端点（如 `https://token-plan-cn.xiaomimimo.com/v1`），
  同为 OpenAI 兼容协议，`/login` 后自定义 Base URL 覆盖即可（模型列表跟着走同一网关）。
- 默认模型只列在售 V2.6 系列：`mimo-v2.6-pro` / `mimo-v2.6-flash` / `mimo-v2.6-pro-ultraspeed`；
  `mimo-v2.5-pro` / `mimo-v2.5` 官方公告 2026.10.21 10:00 下线，不放进默认列表。
- context-window 推断表登记：`mimo-v2.6*` 1M、`mimo-v2.5-pro` 1M、`mimo-v2.5-omni` 131072、
  `mimo-v2-flash` 131072（官方博客标 256K、接入指南标 56K，冲突时取小值）、`mimo-7b*` 32768。
