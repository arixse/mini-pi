## 新增 Anthropic 官方模型提供商（commit c94bf02）

- 新增 `src/provider/anthropic.ts`（`AnthropicProvider`）：name `anthropic`、sdkType `Anthropic`、
  baseUrl `https://api.anthropic.com`（**不带 /v1**，Anthropic SDK 自行拼接）。
- 两个与其它 provider 不同的坑（已写进 docs/providers.md 实现步骤）：
  1. 官方鉴权是 `x-api-key` 头 + `anthropic-version: 2023-06-01`，不是 `Authorization: Bearer`；
  2. 模型列表在 `/v1/models`，而 Base URL 不带 /v1 → 必须覆写 `getModelsUrl()`，
     直接 `buildModelsUrl()` 拼出 `/models` 会 404。
- 默认模型按官方推荐顺序：`claude-opus-5-5`（1M）/ `claude-sonnet-5-5`（1M）/
  `claude-haiku-4-5`（200K）/ `claude-fable-5-1`（1M）。
- context-window：5.5/5 世代 1M；Haiku 4.5、Opus/Sonnet 4.x、3.x 世代 200K；`claude*` 兜底 200K。
  4.x 的 1M 需要 `context-1m-*` beta 头才生效，未开启时是 200K，故按 200K 登记（估大会 400）。
- 验证：tsc 全绿；provider 169 例（166 pass / 0 fail / 3 skipped）、cli 163 全过、
  agent（除 tools）204 全过。

## 新增智谱（Zhipu / GLM）模型提供商（commit 83ac1dd）

- 新增 `src/provider/zhipu.ts`（`ZhipuProvider`）：name `zhipu`、sdkType `OpenAI`、
  baseUrl `https://open.bigmodel.cn/api/paas/v4`，鉴权标准 `Bearer`（Key 形如 `id.secret`），
  模型列表与 Base URL 同源（`/models`）。
- **三协议端点选 OpenAI Chat Completion**：智谱同时提供 OpenAI Chat Completion
  （`/api/paas/v4`）、OpenAI Response（`/api/v1`）、Anthropic Message（`/api/anthropic`）。
  官方 GLM-5.3 文档注明"订阅过 GLM Coding Plan（含已过期）的用户暂时只能走 Chat Completion"，
  故选它覆盖面最广。
- 默认模型只列文本/编码类在售模型：`glm-5.3` / `glm-5.2` / `glm-5.1` / `glm-4.7` / `glm-4.6`。
  视觉、图像、音视频、向量模型（GLM-5V / CogView / CogVideoX / Embedding）走各自专属接口，
  放进对话列表会误导选择——这条已写进 zhipu.test.ts 的断言。
- context-window 登记：`glm-5.3` / `glm-5.2` 1M；`glm-5.1` / `glm-5` / `glm-4.7` / `glm-4.6` 200K；
  `glm-4.5-air` / `glm-4.5` / `glm-4` 128K；小窗口的 `glm-4.1v-thinking*` 65536、
  `glm-4v-flash` 16384 必须显式登记（否则超窗 400）；`glm-4-long` 1M（输出仅 4K）、
  `glm-4.6v` 128K，两者靠更长前缀压过 `glm-4` / `glm-4.6`。
- 验证：tsc 全绿；全量 644 例（641 pass / 0 fail / 3 skipped）。
