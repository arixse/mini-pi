## 全项目代码审查（优化点梳理）

通读 src 全部 31 个源文件 + docs/notes，产出优化点清单（未改代码，仅分析）。

### P0（正确性 / 安全 / 明显性能）

1. **bash 可绕过凭据保护**：`assertNotCredentialFile` 只挂在 `read_file` / `write_file` / `edit_file`
   （tools.ts:587/702/778），`checkBashCommand` 只对绝对路径与 `..` 做校验，`cat .env`（相对路径）
   会被放行。README 声称「.env 默认禁止读写」，与实现不符。
2. **会话落盘未批量**：`appendAgentMessages`（repl.ts:805）逐条 `await appendMessage` → 每条一次
   `appendFile` + 一次 `syncContext`（buildContext 全链回溯）。一个 turn N 条消息 = N 次 syscall + N 次 O(n)。
3. **token 估算每轮全量重算**：`needsCompaction` → `estimateTokens(buildContext())`，
   `estimateMessageTokens` 对每个 toolCall 做 `JSON.stringify`。每轮 turn_end 都跑一遍，长会话明显卡顿。
4. **grep 串行读文件**：`walkEntries` 的 visit 回调里 `await readSearchableFile`，逐个文件串行；
   `createWorkspaceIgnore` 每次工具调用都重读并重建 .gitignore matcher。

## 落地 5 项优化（代码已改）

1. **bash 凭据守卫**（tools.ts）：新增 `findCredentialMentions()`，命令按 shell 元字符切片、
   片段再按 `= : \ /` 切开，逐段走 `isCredentialFile`；`checkBashCommand` 命中即抛错。
   （`cat .env` / `./config/.env` / `--file=.env` 都能拦；`dotenv`、`foo.env`、`.env.example` 不误伤。）
2. **OpenAI 补 max_tokens**（model.ts）：新增纯函数 `buildOpenAIRequest()` + `resolveMaxTokens()` +
   `isUnsupportedMaxTokensError()`；推理型模型（`/^o\d/i`）改发 `max_completion_tokens`；
   网关不认或值超上限时自动降级为不下发（与 stream_options 降级同一套路）。
3. **统一 logger**（新增 src/shared/logger.ts）：26 处 `console.error` 全部换成
   `logger.error/warn`；默认写 stderr（stdout 留给对话正文），级别由 `MINI_PI_LOG_LEVEL` 控制，
   落点可用 `configureLogger({sink})` 替换（测试不再 monkey patch console）。
   注意：面向用户的 UI 输出（卡片、提示、状态行）仍直接 console.log，不走 logger。
4. **token 用量累计**（新增 src/agent/usage.ts）：`createUsageTracker()` 在 repl 每轮结束后
   `recordTurn(result.newMessages)`；`/status` 新增「用量」行（输入/输出/合计/请求数/上一轮，
   提供方未返回用量时明确说明）；切会话 /new 与 /clear 会 reset。
5. **覆盖率门槛**（package.json）：新增 `test:coverage`（node 内置 coverage，
   `--test-coverage-lines=85 --branches=85 --functions=90`，排除 `**/*.test.ts` 与 `**/shim/*.cjs`），
   `check` = typecheck + test:coverage。

验证：`npm run check` 全绿（699 tests / 696 pass / 3 skipped；覆盖率 87.96 / 89.96 / 92.19），
`npm run build:cli` 正常（仅一条既有的 esbuild "es2025" 警告）。
