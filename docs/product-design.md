# Mini Pi Code Agent 产品设计文档

## 1. 产品概述

Mini Pi Code Agent 是一个轻量级的 AI 编程助手，具备 pi-code-agent 的核心功能，旨在为开发者提供智能代码辅助能力。

## 2. 交互模式

### 2.1 命令行交互（第一阶段）
- 终端命令行界面
- 支持多轮对话
- 实时流式输出
- 快捷键支持

### 2.2 页面交互（第二阶段）
- Web 图形界面
- 可视化文件操作
- 代码高亮显示

## 3. 核心功能

### 3.1 智能对话
- 支持多轮对话，理解上下文
- 支持 OpenAI 和 Anthropic 模型切换
- 流式响应输出

### 3.2 文件操作
- 读取文件内容
- 创建/编辑文件
- 执行 bash 命令

### 3.3 工具调用
- 函数调用（Function Calling）
- 工具结果解析和处理
- 错误处理和重试机制

### 3.4 会话管理
- 会话状态保持
- 历史消息管理
- 上下文窗口控制

## 4. 技术架构

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   前端界面       │    │   API 服务器     │    │   AI 模型       │
│   (HTML/JS)     │◄──►│   (Node.js)     │◄──►│   (OpenAI/      │
│                 │    │                 │    │    Anthropic)   │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 5. 用户交互流程

1. 用户输入问题或指令
2. 系统解析意图，选择合适工具
3. 执行工具调用（读取文件、执行命令等）
4. 返回结果给用户
5. 支持多轮对话直到任务完成

## 6. 配置要求

- Node.js 18+
- API 密钥（OpenAI 或 Anthropic）
- 环境变量配置

## 7. 安全考虑

- API 密钥安全存储
- 命令执行权限控制
- 输入验证和 sanitization
