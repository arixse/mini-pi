# Mini Pi Code Agent 产品设计文档

## 1. 产品概述

Mini Pi Code Agent 是一个轻量级的 AI 编程助手，具备 pi-code-agent 的核心功能，旨在为开发者提供智能代码辅助能力。

核心定位：**把任务真正做完，而不是描述该怎么做**。

## 2. 交互模式

### 2.1 命令行交互（第一阶段）

- 终端命令行界面
- 支持多轮对话
- 实时流式输出
- 斜杠命令支持（`/new`、`/login`、`/model`、`/help` 等）

### 2.2 页面交互（第二阶段，已实现）

> Web 界面与 Electron 桌面壳均已落地，共用同一套内核与 HTTP + SSE 契约；
> 服务端与前端入口分别在 `packages/client/src/server` 与 `packages/client/src/web`。

- Web 图形界面
- 可视化文件操作
- 代码高亮显示

## 3. 核心功能

| 功能 | 说明 |
| --- | --- |
| 智能对话 | 多轮对话理解上下文，9 家供应商模型切换，流式响应 |
| 文件操作 | 读取、创建、编辑文件（均需用户审批） |
| 命令执行 | bash 命令执行（超时保护、高危命令警告） |
| 会话管理 | 会话状态保持、历史消息管理、上下文窗口控制 |
| 子 Agent 委派 | 把相对独立的任务交给子 Agent 处理（默认关闭） |

## 4. 配置要求

- **运行时**：Node.js 22+
- **API 密钥**：任一家已注册供应商，通过 `/login` 命令配置
- **模型选择**：通过 `/model` 命令配置

## 5. 安全考虑

| 方面 | 措施 |
| --- | --- |
| API 密钥存储 | `auth.json` / `settings.json` 以 0600 权限落盘 |
| 命令执行权限控制 | `write_file` / `edit_file` / `bash` 执行前必须由用户逐次确认 |
| 文件访问边界 | 所有文件操作限制在工作区内，symlink 指向外部同样被拒绝 |
| 凭据保护 | `.env*`、SSH 私钥、`*.pem` / `*.key`、`.npmrc` 等默认禁止读写 |
| 可中断 | Ctrl+C 取消当前任务，模型请求 120 秒超时 |

详细行为规范见 [CLI 交互文档](cli-interaction.md)。
